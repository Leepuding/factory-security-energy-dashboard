# 非标件自动报价系统演示资料包

本资料包仅用于产品演示、流程讲解和页面测试，不可作为真实生产依据。

## 推荐演示顺序

### 1. 完整 2D + 3D 自动报价

文件夹：`01_完整2D+3D_伺服电机安装座`

- 同时上传 `伺服电机安装座.step` 和 `伺服电机安装座.pdf`。
- 询价数量：20 件。
- 期望交期：8 个工作日。
- 演示重点：同名图纸自动配对、联合识别、工程核价、销售报价。
- 建议讲解结果：6061-T6、本色阳极氧化、CNC 粗铣/精铣、钻孔攻丝、CMM 检测。

### 2. 只有 3D 图纸的人工补录

文件夹：`02_仅3D_分度盘连接轴`

- 上传 `分度盘连接轴.step`。
- 询价数量：50 件。
- 演示重点：可识别外形尺寸，但材料、公差、热处理和粗糙度需要人工补录。
- 建议补录：40Cr、调质 28-32HRC、外圆磨削 Ra0.8。

### 3. 只有 2D 图纸的人工补录

文件夹：`03_仅2D_钣金折弯支架`

- 上传 `钣金折弯支架.pdf`。
- 询价数量：100 件。
- 演示重点：可识别材料、板厚、孔位、折弯和表面要求，但缺少三维体积与重量。
- 建议工艺：激光下料、两次折弯、去毛刺、拉丝。

### 4. 2D 与 3D 信息冲突

文件夹：`04_2D与3D冲突_传感器法兰`

- 同时上传 `传感器法兰.step` 和 `传感器法兰.pdf`。
- 询价数量：12 件。
- 3D 文件材料属性：6061-T6。
- 2D 图纸材料：TC4 钛合金。
- 演示重点：系统应暂停自动确认，提示材料冲突并要求工程人员选择正确版本。

### 5. 多工艺组合报价

文件夹：`05_组合工艺_齿轮箱端盖`

- 同时上传 `齿轮箱端盖.step` 和 `齿轮箱端盖.pdf`。
- 询价数量：16 件。
- 演示重点：车削、铣削、钻攻、调质、磨削、发黑、三坐标检测和包装的组合成本。

## 规则与基础数据

文件夹：`06_规则与基础数据`

Excel 文件包含 5 个工作表：

1. `规则总览`：规则版本、税率、目标毛利、风险阈值和加工能力边界。
2. `材料与设备`：材料密度/价格/利用率、设备能力及准备/加工费率。
3. `工序与外协`：标准工序公式、刀具磨损率、热处理、表面处理、检测和包装价格。
4. `报价计算示例`：引用基础数据自动计算制造成本、售价、税费和毛利。
5. `历史报价样例`：12 条覆盖主要工艺的历史报价，可用于相似件和准确率看板演示。

黄色单元格代表可调整输入，蓝绿色单元格代表跨表规则引用。

## 文件边界

- PDF 是可阅读的演示工程图，包含尺寸、材料和技术要求。
- STEP 是轻量级 ISO-10303-21 演示文件，用于验证上传、同名配对和流程状态；并非真实可生产的精确三维模型。
- 当前 Web Demo 对图纸内容采用模拟解析，因此演示结果主要由文件组合和页面操作触发。
