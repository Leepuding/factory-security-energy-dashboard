# 非标件 AI 自动报价 Demo

一个纯前端、单页面的 React 演示应用，主流程只有：

`上传图纸 → AI 识别与规则解析 → 报价结果`

## 演示能力

- 上传同一零件的 STEP/STP/IGS/IGES 与 PDF/DWG/DXF 文件。
- 通过文件名匹配预置识别结果，并用五步动画模拟 AI 解析。
- 仅有 2D 或仅有 3D 时继续报价，同时展示低置信度与默认参数提示。
- 检测演示材料冲突并暂停价格生成，选择材料后即时恢复报价。
- 展示识别字段、工艺路线、风险提示、成本明细与含税价格。
- 在右侧规则抽屉调整材料价、费率、磨损、风险、毛利、税率和交期，报价即时联动。
- 导出兼容 Excel 的报价文件。

## 演示文件

解压或直接使用 [demo-package](./demo-package) 中的五组场景：

1. 完整 2D + 3D：伺服电机安装座。
2. 仅 3D：分度盘连接轴。
3. 仅 2D：钣金折弯支架。
4. 2D/3D 材料冲突：传感器法兰。
5. 组合工艺：齿轮箱端盖。

规则与历史数据示例位于 `demo-package/06_规则与基础数据`。

## 运行

```bash
npm install
npm run dev
```

生产构建：

```bash
npm run build
npm run preview
```

## Demo 边界

- 不接入真实 CAD、OCR 或 AI 服务。
- 不包含账号、角色、询价历史、审批、邮件、订单、数据库和后端服务。
- 规则修改只在当前页面会话中生效，刷新后恢复默认值。
- 报价结果为演示估算，不作为正式生产或交易依据。
